# ごはん記録（食事管理 PWA）

スマホで片手で使える食事管理アプリ。データは端末内（IndexedDB）だけに保存し、AI の API は使わない（費用 0 円）。
写真からのカロリー推定・アドバイス・献立づくりは、利用者自身の Claude（claude.ai／Claude アプリ、無料プランでも可）に任せる。

## 機能

| 区分 | 機能 |
|---|---|
| 記録 | 朝・昼・夕・間食ごとの記録、写真の添付、品目の手入力（kcal・P/F/C） |
| Claude 連携 | 写真を共有シートで Claude アプリへ送る／文章で推定を依頼する／その日の食事でアドバイスをもらう／献立を作ってもらう |
| 取り込み | Claude の回答をコピー →「回答を貼り付けて取り込む」で品目・献立を自動入力 |
| 目標 | 性別・年齢・身長・体重・活動量・目標（減量/維持/増量）から目標カロリーと PFC を自動算出（手動設定も可） |
| 体重 | 体重・体脂肪率の記録、1か月/3か月/1年のグラフ、BMI |
| 水分 | コップ1杯をワンタップで記録 |
| 便利機能 | Myメニュー（よく食べる組み合わせ）、最近食べたものから追加、献立計画、献立から買い物リスト自動作成・共有 |
| データ | バックアップ（JSON、写真は除く）と復元 |

## Claude 連携のしくみ

1. アプリが指示文（プロンプト）を作り、クリップボードにコピーして `https://claude.ai/new?q=…` を開く
   - スマホで写真があるときは、Web Share API で写真と指示文を共有シートに渡す（送信先で Claude アプリを選ぶ）
   - URL が長すぎる場合は `?q=` を付けず、クリップボードから貼り付けてもらう
2. 指示文の最後で、`{"items":[…]}` や `{"plans":[…]}` 形式の JSON をコードブロックで付けるよう依頼している
3. 回答をコピーしてアプリに戻り「貼り付けて取り込む」を押すと、`src/logic/claude.ts` の `parseReply` が JSON を読み取る
   （コードブロックが崩れていても、全角数字や "234kcal" のような表記でも読める）

推定値は目安なので、取り込んだ記録には「推定」タグを付け、画面上で修正できるようにしている。

## 開発

```bash
cd meal-app
npm install
npm run dev     # 開発サーバー
npm test        # 目標カロリー計算・回答の取り込み・買い物リスト集計のテスト
npm run build   # 本番ビルド（dist/）
```

## 構成

| パス | 内容 |
|---|---|
| `src/logic/nutrition.ts` | 基礎代謝（Mifflin-St Jeor 式）・目標カロリー・PFC |
| `src/logic/claude.ts` | Claude への指示文の作成、共有・コピー、回答の取り込み |
| `src/logic/shopping.ts` | 献立の食材を買い物リストにまとめる |
| `src/db.ts` | IndexedDB（Dexie）とバックアップ |
| `src/screens/` | きょう・記録・献立/買い物・体重・設定 |

## 公開

既定ブランチへのプッシュで、試験アプリと一緒に GitHub Pages の `/<リポジトリ名>/meal/` に公開される（`.github/workflows/deploy.yml`）。
スマホのブラウザで開き「ホーム画面に追加」するとアプリのように使える。
